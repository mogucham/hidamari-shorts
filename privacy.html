プライバシーポリシー

最終更新日：2026年11月13日

Hidamari Shorts（以下「本ツール」）は、YouTubeチャンネル「ひだまり食堂のユキ」の運営者が、自分のチャンネルに動画をアップロードするためだけに使う個人用のツールです。

使う情報

  • YouTube Data API を通じて、運営者自身のチャンネル名の確認と、動画のアップロードを行います。
  • Googleから受け取る認証情報（トークン）は、運営者のパソコンの中だけに保存します。

第三者への提供

本ツールが扱う情報を、第三者に送ったり、売ったり、共有したりすることはありません。広告や分析のためにも使いません。

Googleのデータの扱い

本ツールがGoogle APIから受け取った情報の使い方と移転は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

許可の取り消し

Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールへの許可を取り消せます。

お問い合わせ

YouTubeチャンネル「ひだまり食堂のユキ」からご連絡ください。

Privacy Policy (English)

Hidamari Shorts is a personal tool used only by the owner of the YouTube channel "Hidamari Shokudo no Yuki" to upload videos to their own channel. It uses the YouTube Data API to confirm the channel name and upload videos. OAuth tokens are stored only on the owner's computer. No data is sold, shared with third parties, or used for advertising or analytics. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
